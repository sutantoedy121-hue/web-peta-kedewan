Identitas & Kontak Situs

Dipakai sebagai judul singkat / nama situs.
Unggah file gambar logo (PNG, JPG, WEBP, atau SVG, disarankan persegi & latar transparan, maks. 2MB). Gambar otomatis diunggah ke penyimpanan & tersimpan saat Anda klik "Simpan Identitas Situs" di bawah. Kosongkan / hapus & simpan untuk kembali memakai ikon bawaan.
Tampil sebagai judul kolom kedua di footer situs publik (menggantikan "Kantor Kecamatan").
Tampil sebagai ikon email (mailto) di footer. Kosongkan untuk menyembunyikan ikon.

Peta Kecamatan (iframe)

Bagian Peta Kecamatan di beranda publik menampilkan peta ini lewat kode iframe — gratis, tanpa API key, cukup tempel satu kode/link embed dari Google Maps di bawah ini.

Boleh tempel link saja, atau seluruh kode <iframe>...</iframe> dari Google Maps — link-nya akan diambil otomatis. Kosongkan & simpan untuk menyembunyikan peta dari halaman publik.
✅ Peta aktif. Lihat beranda publik →
Belum pernah pakai iframe? Klik untuk lihat panduan singkat
  1. Buka Google Maps di browser (tidak perlu login).
  2. Ketik "Kecamatan Kedewan, Bojonegoro" di kolom pencarian lalu tekan Enter.
  3. Klik tombol Bagikan (Share) di panel sebelah kiri.
  4. Pilih tab Sematkan peta (Embed a map) — bukan tab "Kirim link".
  5. Klik Salin HTML (Copy HTML) untuk menyalin kode <iframe src="...">.
  6. Tempel kode itu apa adanya ke kolom di atas — tidak perlu diedit dulu, sistem ini mengambil link-nya sendiri.
  7. Klik Simpan Peta, lalu buka beranda publik untuk mengecek hasilnya.

Background Hero (Slide Otomatis)

Gambar latar belakang bagian hero (paling atas) di beranda publik. Bisa unggah lebih dari satu gambar sekaligus — kalau lebih dari satu, tampilannya otomatis bergantian (slide) tiap 10 detik. Setiap unggah/hapus langsung tersimpan, tidak perlu tombol simpan terpisah.

Format PNG, JPG, atau WEBP, disarankan foto lanskap (mis. 1920×1080), maks. 5MB per gambar. Bisa pilih beberapa file sekaligus dari dialog unggah.
Memuat…
Angka kecil di pojok tiap gambar menunjukkan urutan tampil di slideshow. Kalau hanya ada 1 gambar, hero tidak akan bergeser (statis). Kosongkan semua gambar untuk kembali ke tampilan hero polos.
